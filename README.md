## ✨ Pourquoi GENEⵣIS Studio ?

Concevez des interfaces Python PyQt6 en quelques minutes : **widgets, thèmes, langues et compilation**. Posez vos composants sur le canvas, peaufinez les propriétés, exportez le code — sans écrire une ligne à la main.

## 🚀 Fonctionnalités

- **30+ widgets intégrés** : boutons, champs, listes, tableaux, onglets, sliders, jauges…
- **10 thèmes** prêts à l'emploi pour vos applications
- **9 langues** d'interface (FR, EN, AR, DE, ES, IT, PT, RU, ZH)
- **6 styles de barre de titre** personnalisables
- **Éditeur QSS** intégré pour un style avancé
- **Export de code Python** directement exploitable
